# 刷钱机 v3 试验结果（2026-10-15）

**结论：12 个试验全部跑完，没有一个通过门槛 A。** 按开跑前登记的规则，v3 不自动进入模拟盘。ML_v2 和随机对照组的前向测试一行没改，照常运行。锁定考试区（2026-04-01 起）没有读取。

明细：`runs/ml/v3_report.md`（全部试验）、`runs/ml/trials.sqlite`（类别 `dev-v3`，每次试验的配置和逐日收益）、`runs/ml/placebo_v3_*.parquet`（随机对照分布）。代码：`src/moneymachine/ml/research_v3.py`。

## 1. 全部 12 个试验

评估区间：干净窗口 2024-07-01 → 2026-03-28（约 1.7 年），扣全部成本。基准 v2：净 Sharpe 1.45。

| 试验 | 净 Sharpe | 比 v2 | 年化收益 | 最大回撤 | 换手/天 | 年化成本 | 年化资金费 | 说明 |
|---|---|---|---|---|---|---|---|---|
| A1a 信号平滑（半衰期 2 天） | **1.95** | +0.50 | +29.3% | 11.5% | 0.035 | 1.0% | −4.3% | 换手减半（修正后重跑，见第 6 节） |
| A1b 信号平滑（半衰期 5 天） | **1.98** | +0.53 | +28.6% | 12.0% | 0.029 | 0.8% | −4.2% | 修正后重跑 |
| A2 资金费进预期收益 | 1.61 | +0.16 | +25.6% | 9.7% | 0.076 | 2.3% | **+5.4%** | 由付资金费变成收资金费 |
| A3 预测 3 天 | 1.10 | −0.35 | +6.3% | 3.9% | 0.004 | 0.1% | −2.4% | 平均仓位只有 21%，几乎不交易 |
| B1a 集中版，多空各 5 个 | **2.15** | +0.70 | +71.8% | 24.8% | 0.617 | 14.6% | −12.5% | 回撤超限 |
| B1b 集中版，多空各 8 个 | **2.08** | +0.63 | +57.5% | 16.7% | 0.388 | 9.0% | −9.2% | |
| B2a 宽币池（v2 构建方法） | **2.06** | +0.61 | +38.3% | 12.0% | 0.071 | 2.3% | −11.2% | 见第 3 节 |
| B2b 宽币池 + 集中版 | 0.26 | −1.19 | +10.4% | 38.9% | 0.715 | 18.5% | −32.3% | 小币集中持有，成本和资金费太高 |
| C1a 加跨交易所特征 | 1.33 | −0.12 | +21.5% | 11.1% | 0.070 | 2.1% | −4.6% | |
| C1b 单独的资金费差信号 | 1.24 | −0.21 | +17.7% | 15.5% | 0.081 | 2.4% | +0.5% | |
| C2 事件特征 | 1.46 | +0.01 | +23.8% | 10.5% | 0.071 | 2.1% | −4.7% | |
| D1 微调 Kronos | 1.22 | −0.23 | +19.7% | 13.8% | 0.082 | 2.5% | −4.1% | |

按方向看：
- **降成本（A）有效**：平滑信号是这次最干净的改进，和 v2 用同一个币池，只是交易得更少。
- **小资金集中版（B1）有效**：500 / 1000 / 2000 USDT 的结果几乎一样（Sharpe 2.17 / 2.15 / 2.14），没有一个币因为最小下单量而下不了单。
- **新信息（C1、C2）和微调模型（D1）无效**：跨交易所、事件、微调 Kronos 都没有带来新的预测能力。用 LightGBM 的分段检验看，加了这些特征之后排序相关系数和 v2 一样（0.114–0.115），说明是特征本身没有新信息，不是模型没训好。微调把 Kronos 的 K 线预测误差从 2.77 降到 2.20，但选币能力不变（排序相关系数 0.030 → 0.031）。

| 检查项 | A1a | B1a | B1b | B2a |
|---|---|---|---|---|
| 净 Sharpe ≥ 1.0 | ✓ | ✓ | ✓ | ✓ |

| **DSR ≥ 0.95** | ✗ 0.61 | ✗ 0.68 | ✗ 0.66 | ✗ 0.64 |

| ≥ 70% 季度为正 | ✓ | ✓ | ✓ | ✓ |
| 最大回撤 ≤ 20% | ✓ | ✗ 24.8% | ✓ | ✓ |
| 成本翻倍后 Sharpe ≥ 0.5 | ✓ 1.13 | ✓ 1.72 | ✓ 1.76 | ✓ 0.83 |
| 前两个币贡献 < 50% | ✓ | ✓ | ✓ | ✓ |
| BTC 暴露 \|β\| < 0.05 | ✓ | ✓ | ✓ | ✓ |

**为什么 DSR 过不了**：一共登记了 59 次试验，纯运气在其中能出现的最好年化 Sharpe 约 1.77。窗口只有 1.7 年，要让 DSR 达到 0.95，Sharpe 大约要到 3。这个门槛在现有开发数据上几乎不可能通过，这也是它的设计目的：不让"多试几次总能碰到好看的"混过去。

## 3. 稳健性检查

**和随机信号比**（同样的构建方法，信号换成 100 个随机种子；平滑版的随机信号也做同样的平滑）：

| 试验 | 随机信号中位数 | 随机 5%–95% | 随机最好 | 模型 | p 值 |
|---|---|---|---|---|---|
| v2（参考） | −0.22 | −1.44 ~ 0.90 | — | 1.45 | 0.02 |
| A1a（修正后的平滑） | 0.09 | −1.43 ~ 1.21 | 2.44 | 1.95 | 0.02 |
| B1a | −0.88 | −1.78 ~ 0.25 | 0.79 | 2.15 | 0.01 |
| B1b | −0.73 | −1.82 ~ 0.46 | 0.62 | 2.08 | 0.01 |
| B2a（宽币池上重跑） | −0.22 | −1.48 ~ 0.85 | 1.14 | 2.06 | 0.01 |

- 平滑本身就会抬高随机信号的成绩（中位数从 −0.22 升到 0.07），因为换手少了、成本低了。所以 A1a 比 v2 多出来的那部分，有一块只是省下的成本。
- 有一个随机种子在平滑构建下达到了 2.44，比模型的 1.95 还高。1.7 年窗口里，Sharpe 的误差本身就有 ±0.8 左右。

**最近的季度在变弱**（各季度净收益，2026Q1 截至 3 月 28 日）：

| | 2025Q2 | 2025Q3 | 2025Q4 | 2026Q1 |
|---|---|---|---|---|
| v2 | +0.0% | +19.4% | +1.5% | −4.5% |
| A1a | +1.3% | +22.2% | +9.6% | −5.3% |
| B1a | +20.8% | +24.0% | +11.7% | +2.6% |
| B1b | +0.7% | +17.3% | +22.2% | −4.2% |
| B2a | +12.7% | +18.0% | −0.8% | −0.5% |

所有候选在 2026Q1 都很弱。可能是正常波动，也可能是信号在衰减，现在的数据区分不开。前向模拟盘会给出答案。

**利润从哪里来**：
- B1a：空头腿年化 +75%，多头 +15%。
- B2a：空头 +52%，多头约 0。其中日均成交额不到 2000 万美元的小币贡献了年化约 28.5%（成本前）。B2a 比 v2 多出来的部分，主要来自小币。

**宽币池的幸存者偏差（B2a 最大的隐患）**：评估期内 OKX 至少下架了约 30 个永续合约，例如 AI16Z、ZKJ、UXLINK、KLAY、BAL、MEMEFI、EOS，另外还有一些没写币名的"若干合约下架"公告。这些币不在我们的数据里，其中 ZKJ、UXLINK 在下架前暴跌了 80% 以上。小币被下架的比例远高于大币，所以 B2a 的结果偏差最大，方向也不确定。v2 的大币池也有同样的问题，但轻得多。

## 4. 这意味着什么

1. **预测能力是真的**：不管换哪种构建方法，模型都稳定地比随机信号好（p ≈ 0.01–0.02）。
2. **能提高收益的是"怎么交易"，不是"更多数据"**：平滑和集中持有有效；跨交易所、事件、微调都无效。
3. **证据仍然不够**：1.7 年的窗口加上 59 次试验，开发数据已经榨不出更多结论了。继续试只会让门槛越来越高。
4. **下一步真正的证据只能来自前向测试**：ML_v2 的 56 天在 12 月 10 日左右到期。

## 5. 可选的下一步（需要你决定）

1. **按规则办**：v3 不进模拟盘，等 ML_v2 的前向结果。
2. **把 v3 的一两个候选作为"探索组"加进模拟盘**（v2 当初也是没过门槛 A、由你决定前向测试的）：
   - **B1b（小资金集中版，多空各 8 个）**：和你打算上真钱的小资金场景最相关，回撤也在 20% 以内。
   - **A1a（信号平滑）**：和 v2 最接近，改动最小，可以直接看"平滑"在前向是否也有效。
   - 需要先写生产代码：集中版要按最小下单量取整；平滑要保存每天的信号。各自从加入那天起单独计时 56 天，和 ML_v2 同期比较，并明确标注"未过门槛 A"。
3. **补数据**：从 OKX 的历史数据下载区找回已下架合约的 K 线，消除幸存者偏差后，再决定宽币池值不值得做。

## 6. 更正（2026-10-15 晚）

- **A1 的平滑实现有 bug，已修正并重跑**：研究版的平滑函数没有剔除当天没有信号的币，标准化时把它们填成了 0。结果是 3,520 个"在币池里、但 Kronos 没法打分"的币日，以 0 信号的身份参与了优化。这是在给实盘写平滑代码时，"实盘逐日平滑 = 研究平滑"的一致性测试发现的。修正后按同样的定义重跑（配置相同，记录覆盖，试验总数仍是 59）：A1a 1.97 → **1.95**，A1b 1.90 → **1.98**。结论不变。A1a 的随机对照已用修正后的平滑重跑：中位数 0.09，模型仍比 100 个中的 99 个好（p = 0.02）。
- **B2a 的随机对照第一次算错了**：诊断代码没有用宽币池，而是在 v2 的币池上跑的，所以得到的分布和 v2 完全一样。代码已修正，在宽币池上重跑：模型的 2.06 比 100 个随机信号全都好（p ≈ 0.01）。所以宽币池的信号也不是构建方法本身造出来的，但幸存者偏差的问题依然存在。

## 7. 决定（2026-10-15，用户选择）

把 **B1b（小资金集中版）** 和 **A1a（信号平滑）** 作为"探索组"加入模拟盘，并各配一个同样构建方法的随机对照组（同一个种子）：

| 账户 | 构建方法 | 初始资金 | 对照组 |
|---|---|---|---|
| `A1a_smoothed` | v2 信号 → 平滑（半衰期 2 天）→ v2 优化器 | 100,000 | `P2_placebo_smoothed` |
| `B1b_concentrated` | v2 信号 → 多空各 8 个，缓冲区 16，按最小下单量取整，BTC 对冲 | 1,000 | `P1_placebo_concentrated` |

- 2026-10-15 15:46 UTC 部署。第一次决策是 2026-10-16 00:00 UTC，56 天后约 2026-12-11 到期。
- 判定规则和 ML_v2 相同（前向 ≥ 56 天、成交 ≥ 100 笔、净收益为正、最大回撤 ≤ 15%），但每个账户只和自己的对照组比，同一段时间比较。ML_v2 仍然只和 P0_placebo 比，它的规则没有变。
- 三个用模型的账户每天共用同一份模型信号（Kronos 采样是随机的，各算各的会不一样），ML_v2 的计算逻辑不变。
- 平滑状态从 10-16 开始积累，前约 5 天是预热期：初始值的权重 7 天后降到约 9%。对照组 P2 也从同一天开始，两边对等。
- 集中版的持仓不做日常再平衡。模拟盘有每日亏损 5% 的风控（所有账户相同），回测里没有这一条，所以集中版在大跌日可能和回测略有不同。
